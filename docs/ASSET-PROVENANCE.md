## Font website

DM Sans (400, 500, 600, 700) dan Playfair Display italic (500) diambil dari distribusi Google Fonts dan disimpan pada `public/fonts/`. Website tidak mengirim permintaan pengunjung ke Google Fonts. Lisensi SIL Open Font License disertakan pada `OFL-DM-Sans.txt` dan `OFL-Playfair-Display.txt`. Warna teks website disesuaikan menjadi lebih gelap untuk meningkatkan kontras pada latar krem; logo asli tidak dimodifikasi.
